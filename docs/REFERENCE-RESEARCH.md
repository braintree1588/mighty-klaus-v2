## Applied principles (original interpretation)

- Richly illustrated, coherent spaces replace flat miniature-board graphics.
- An original Victorian Christmas workshop, expressive portrait sheet, parchment journal, physical-looking inventory and discreet gold interface establish a cohesive visual world.
- Directly search and collect objects; select inventory items and use them at sensible destinations; short conversations establish needs and acknowledge help.
- Clues and dependencies connect discovery to the Christmas kindness story rather than adding unrelated object hunts.
- Camera regions, bounded zoom and touch scrolling support exploration of a detailed scene. A parallel labelled list supports keyboard and nonvisual exploration.
- Immediate static entry screen; instant dialogue, no typewriter waits, no cinematic intro or video. Only low-amplitude firelight and brief interaction feedback. Reduced-motion option and system preference honored.

## Original project constraints retained

The 44-page original Implementation Blueprint and the pre-presentation Version 2 logic underpin the design: three spirits, nine eventual levels, privacy-preserving Secret Santa, maximum ৳2,000, no combat, no speed penalties, and server authority for the eventual real event. This standalone pitch implements only Christmas Past, with three complete memories. The original pure puzzle reducer was taken from commit cb3363a (before the nickname/avatar presentation demo). The new hidden-object wrapper adds dialogue, exploration and inventory prerequisites without replacing rewind/intervene/resume or the 100-point reward rule.

The reference’s characters, branding, text, backgrounds and game files have not been copied. All new background and character artwork is original image-generated concept art. Existing Mighty logos are the user-supplied assets. The result is an inspired original prototype, not an exact replica or a licensed edition of Pirate’s Treasure.
